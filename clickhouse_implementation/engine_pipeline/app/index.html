Engine condition

One number per minute: how far this engine has drifted from its own quietest behaviour. Computed entirely in ClickHouse (engine.v_engine_minute_anomaly) as a robust median/MAD deviation across five scalars — no single one catches every fault, so they are combined.

Spectrogram

One spectrogram per engine, stacked; a new engine appears as soon as its data arrives. One column per second, one row per frequency bin, computed by the stft_db UDF (the original numpy STFT) inside ClickHouse: each minute is stored in engine.engine_minute_spectrogram once it closes, and only the minute still filling is calculated live.

Health scalars

Three separate charts sharing one time axis, never one chart with two y-axes — the bearing signature is precisely "kurtosis moves while RMS does not", and a shared axis would hide it. Shading is the commanded fault mode. Minutes older than ~10 minutes come from engine.engine_minute_health; newer ones are calculated live from the raw readings.
